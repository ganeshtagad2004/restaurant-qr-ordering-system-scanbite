# ScanBite – Restaurant QR Menu & Admin Panel

ScanBite is a restaurant management system that allows admins to manage menu items, view orders, and control restaurant operations through a simple admin dashboard.

## Features
- Admin Dashboard
- Menu Management (Add, Edit, Delete Items)
- Category Filtering
- Image Upload for Menu Items
- Orders Management
- Tables & QR System

## Tech Stack
- Node.js
- Express.js
- MongoDB
- HTML
- CSS
- JavaScript

## Run the Project

1. Clone the repository

git clone https://github.com/ganeshtagad2004/scanbite-admin-panel.git

2. Install dependencies

npm install

3. Start server

node backend/server.js

4. Open browser

http://localhost:5000
